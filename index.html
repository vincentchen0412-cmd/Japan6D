東北秋日自駕｜10/7–10/12

仙台出發，山形與會津環線，含神社與購物

六天行程

Day 1｜10/7（三）台北 → 仙台10:00 自台北出發，搭電車進市區，入住 ANA Holiday Inn 仙台（今天不取車）
Day 2｜10/8（四）仙台 → 銀山溫泉取車 → 大崎八幡宮 → 鳴子峽 → 能登屋旅館（山形縣尾花澤）
Day 3｜10/9（五）銀山溫泉 → 上山溫泉白銀瀑布 → 山形市區 → 葉山舘（かみのやま温泉）
Day 4｜10/10（六）上山 → 蘆之牧溫泉米澤上杉神社 → 喜多方拉麵 → 會津若松鶴城 → 大川莊
Day 5｜10/11（日）蘆之牧 → 仙台（還車）大內宿 → 開車回仙台還車 → 仙台市區購物
Day 6｜10/12（一）仙台 → 台北鹽竈神社 → 仙台機場線 → 16:05 班機返台（今天不開車）

出發前提醒

  • 租車：10/8 上午仙台站周邊取車、10/11 傍晚還車（10/7、10/12 不開車）；台灣駕照需附日文譯本，建議加 ETC 卡並預約。
  • 飯店：福島大川花 已依資料判斷為「大川荘」；叶山馆 判斷為「葉山舘」；若有誤請告知。
  • 天氣：10/7 距今約 8 天，尚無可靠逐日預報，出發前 3 天再查一次。
  • 洗衣：僅確認 ANA Holiday Inn 仙台有送洗，其餘三家請直接詢問。
  • 行李：10/12 要先寄放飯店再去鹽竈神社，請入住時向櫃台確認。
  • 免稅：購物時帶護照，並確認店家免稅規定。

住宿順序

  • 10/8：能登屋旅館（銀山溫泉）
